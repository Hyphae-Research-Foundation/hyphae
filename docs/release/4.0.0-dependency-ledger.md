## Integration gates

The release remains blocked until one selected integration commit satisfies
all of the following:

1. Its ancestry or reviewed conflict-resolution patch contains every accepted
   lane input, and the ledger is replaced with that exact integration commit.
2. Catalog capability 4 and minor 8 are coherent across catalog, product,
   Rust wire, Python, and TypeScript, including fail-closed down-conversion.
3. Minor 9 carries the bounded embed-and-ingest operation end to end, with
   authorization, admission, transaction, response, and failure-path tests.
4. The offline CPU path remains the default. Any CUDA path is optional,
   reports its exact execution profile, and preserves the versioned fallback
   contract without weakening CPU authority.
5. Qwen-specific execution is claimed only if an exact model profile and its
   retained evidence are both present on the selected commit. Harness support
   alone is not a product profile or execution claim.
6. The complete package, SDK, conformance, security, and hosted release matrix
   passes on the selected commit, followed by a retained exact-SHA G8 closure.

## Exact candidate package commands

The candidate version is deliberately absent from crates.io, so the exact local
dry run packages the complete closure together and then checks the extracted
archives with local patches. Independent `cargo publish --dry-run` calls would
incorrectly require unpublished `=4.0.0` dependencies from the live registry.

```bash
export CARGO_TARGET_DIR=/opt/dlami/nvme/hyphae-targets/12-release-final
cargo package --locked --no-verify \
  -p hyphae-core -p hyphae-native-types \
  -p hyphae-native-ann -p hyphae-native-catalog -p hyphae-native-mvcc \
  -p hyphae-native-pages -p hyphae-native-records -p hyphae-native-wal \
  -p hyphae-query -p hyphae-contracts -p hyphae-native-blobs \
  -p hyphae-native-btree -p hyphae-native-manifest -p hyphae-retrieval \
  -p hyphae-native-runtime -p hyphae-storage -p hyphae-engine \
  -p hyphae-native-product -p hyphae-native-protocol -p hyphae-client \
  -p hyphae-native-daemon -p hyphae-server -p hyphae-cli \
  -p hyphae-pliegors --target-dir "$CARGO_TARGET_DIR/package-dry-run"
python3 tools/check_crate_packages.py
python3 tools/verify_crate_packages.py
```

The first command produced all 24 `4.0.0` archives on the exact H100. The two
fail-closed checks remain blocked by the catalog-package and CLI errors recorded
above. Live publication remains the protected workflow's one-package-at-a-time
`cargo publish --locked -p "$package"` loop after every preceding layer is
visible; none of these local commands grants publication authority.
