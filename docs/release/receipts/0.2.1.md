## Repository governance

GitHub immutable releases were enabled before publication, and the published
release reports `immutable=true`. Active repository ruleset `20045527`,
`Protect version tags`, rejects updates and deletion for `refs/tags/v*` with
no bypass actor.

At post-release inspection, `main` required 17 strict status checks, enforced
protection for administrators and conversation resolution, and disabled force
pushes and deletion. It required zero approving reviews and did not require
CODEOWNER review or last-push approval. Those review controls remain an
explicit governance residual. The signed checks report is tamper-evident
release evidence, not an independent trust root against a repository writer
who can change workflows.
